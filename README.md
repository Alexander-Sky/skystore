# Skystore

Интернет-магазин на Django для продажи плагинов и примеров кода.

## Технологии
- Python 3.14
- Django 6.0.6
- Poetry
- Bootstrap 5

## Установка и запуск

```bash
git clone <repository-url>
cd skystore
poetry install
poetry run python manage.py migrate
poetry run python manage.py runserver
Открыть: http://127.0.0.1:8000/
